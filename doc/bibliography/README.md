# Библиография проекта

Подборка статей, инструментов, стандартов и патентов по теме build provenance,
SBOM и supply chain security.

| Файл | Назначение |
|------|-----------|
| `papers.bib` | Метаданные (BibTeX) — source of truth для цитирования в статье |
| `ANNOTATIONS.md` | Аннотации: механизм, отличия от нашего подхода, статус прочтения |
| `GOALS.md` | Цели подборки и приоритеты чтения |
| `NOTES.md` | Рабочие заметки: итоги поисков, методика чтения |
| `translations/` | Русские переводы ключевых источников (`<bibtex-key>.ru.md`) |
| `pdf/` | Локальные копии PDF (не в git, см. .gitignore) |

## Правила ведения

1. Один источник = одна запись в `papers.bib` + одна секция в `ANNOTATIONS.md`
   с тем же ключом.
2. Обязательные поля аннотации: **Статус**, **Механизм**,
   **Чего НЕТ (vs наш подход)**, **Для статьи**.
3. Незаполненные метаданные помечать `TODO:` прямо в .bib.
4. PDF класть в `pdf/` под именем ключа: `pdf/<bibtex-key>.pdf`.

Проверка синтаксиса: `bibtex`-парсеры или `pandoc --citeproc`.
